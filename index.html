A substantial guide to Odin for programmers who want to build real Linux command-line tools: reason about types, allocation, binary data and the C ABI; design dependable CLIs; compose ffmpeg/ffprobe safely; then cross the boundary into FFmpeg’s libav libraries.

Offline-friendly multi-page edition · examples checked with Odin dev-2026-09-nightly:a2fb372

The promise: by the end, you will be able to reason about Odin packages, polymorphic procedures, allocators, byte layouts and foreign calls; design a CLI that composes with Unix; invoke FFmpeg tools without a shell; and explain the libav demux → packet → decoder → frame → filter/encoder → mux pipeline, its ownership rules and its send/receive state machine.

This is a working learning text, not a language or FFmpeg specification. Examples target Linux and were checked with Odin dev-2026-09-nightly:a2fb372 and FFmpeg 6.x libraries. Both projects evolve: use the headers, documentation and source matching the libraries actually installed on your machine.

How to read this book

This is not a syntax flash-card course. It assumes you can already program, read a shell command, and understand basic compilation. The opening moves quickly into Odin’s compilation model, data representation, polymorphism and memory decisions; later chapters slow down at unfamiliar boundaries such as process I/O and the C ABI. Read in order, run the examples, and keep notes about what the compiler and the media tools actually prove.

The loop

Read → run → change → explain

Save one example as main.odin, run the exact command, observe the output, and make one deliberate change. Compiler errors are part of the lesson.

A useful habit

Keep the smallest repro

When a program surprises you, remove unrelated code until the surprise remains. A tiny program teaches faster than a large project.

Working system

Examples target Linux
